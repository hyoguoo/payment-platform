# code-ready 체크리스트

코드 리뷰와 토픽 마무리에서 변경에 해당하는 항목을 적용한다.

## task execution

- [ ] PLAN이 있는 작업이면 완료 결과와 실제 구현이 일치한다.
- [ ] STATE가 실제 진행 상태를 나타낸다.

## test gate

- [ ] 변경된 동작·버그·실패 경로를 검증하는 테스트가 있다.
- [ ] 실행한 검사의 범위와 결과가 확인되고 미검증 항목이 구분되어 있다.
- [ ] 상태 전이는 유효·무효 전이를 검증하고 구현 구조를 그대로 반복하는 테스트에 의존하지 않는다.

## convention

- [ ] 관련 `docs/context/conventions/` 규칙과 정적 분석 결과를 확인했다.
- [ ] 범위 밖 수정과 새로 생긴 죽은 코드가 없다.

## domain risk

- [ ] 민감정보가 로그에 그대로 드러나지 않는다.
- [ ] 중복 요청·재배달·보상·취소가 반복되어도 정합성이 유지된다.
- [ ] PG의 이미 처리된 응답을 주문·금액·상태 대조 없이 수용하지 않는다.
- [ ] 종결 상태의 역행이나 누락된 전이 가드가 없다.
- [ ] 동시 경로의 락·트랜잭션·유니크 제약이 실제 실패 시나리오를 막는다.
- [ ] 부분 실패 후 결제와 재고를 복구할 경로가 있다.
