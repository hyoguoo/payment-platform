# GitHub Wiki 접근

위키는 메인 프로젝트와 별도 Git 저장소다. 저장소 루트를 기준으로 자매 디렉토리
`../payment-platform.wiki`를 먼저 확인한다. 없으면 사용자 제공 경로, 상위 디렉토리의
동명 저장소, 프로젝트 내부 `.wiki` 또는 `wiki`를 확인한다. 후보의 Git remote와 Markdown 파일을
확인해 올바른 위키인지 판단한다. 찾지 못하면 시도한 경로를 알리고 위치를 요청한다.

읽기·수정 전에 위키 저장소의 적용 지침과 Git 상태를 확인한다. `rg --files`와 `rg -n`으로
필요한 페이지만 찾는다. README의 위키 링크는 페이지 슬러그와 실제 내용을 함께 대조한다.
동작 설명이 충돌하면 현재 코드에서 근거를 확인하고, 수정 요청 범위에 따라 반영한다.
페이지 파일명은 외부 링크의 슬러그이므로 변경할 때 참조도 확인한다.

수정 결과는 위키 저장소에서 별도로 확인한다. 게시까지 요청받았으면 그 저장소에서 커밋·푸시를
진행하고, 로컬 수정만 요청받았으면 그 상태를 보고한다. 메인 저장소의 커밋에 포함된다고
설명하지 않는다. 파일은 클릭 가능한 경로와 줄 번호로 전달한다.
