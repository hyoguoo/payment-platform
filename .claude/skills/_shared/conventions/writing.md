## 기존 문서 수정 시

기존 문서를 수정할 때는 세 파일의 컨벤션을 완벽히 준수한다.
수정 범위가 일부라도, 해당 문서 전체가 컨벤션에 맞는지 함께 확인한다.

체크리스트:

- [ ] 문체가 `~다.` 또는 명사형
- [ ] 헤더 단위로 의미 구분
- [ ] 문장 길이가 적절함 (길면 대시로 분리)
- [ ] 평가·과시 형용사·번역투 없음 (사실·수치로 대체)
- [ ] 은유·즉석 조어 없음 (개념은 이름 그대로)
- [ ] 메타 도입어("결론적으로", "핵심은" 등) 없음
- [ ] 명사화 남발 없음 ("~하는 것" → 동사)
- [ ] 같은 구조 3개 이상 균일 병렬 나열 없음
- [ ] 짧은 단정문 연발 없이 연결어미로 자연스러운 문장 (긴 불릿은 하위 뎁스로 분해)
- [ ] 검증된 내용만 포함
- [ ] prose 본문에 메서드 호출 narrative(`X.foo()` 패턴) 없음
- [ ] 설계 옵션·결정에 `Option A/B` 같은 즉석 코드 라벨 없음 (내용으로 명명)
- [ ] 동의어 통일 표 기준에 맞게 표기됨
- [ ] 약어 첫 등장 시 풀어쓰기 1회 적용
